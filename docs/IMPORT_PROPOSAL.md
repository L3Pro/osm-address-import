# OSM import proposal — working template, NOT SUBMITTED

**State: NOT APPROVED. This is an internal drafting checklist, not a public claim that consultation occurred.**

Before any live edit, publish a compliant plan on the OSM Wiki and consult the relevant local community, then submit a formal import proposal to the OSM Community Forum.
