# Code of conduct

We want constructive, inclusive, evidence-based collaboration. Treat other contributors and local OSM mappers respectfully; critique data and implementations, not people. Avoid harassment, discrimination, threats, exposing private information, or using the project to evade OSM community decisions.

Report community-conduct problems privately to the repository maintainer through GitHub; public issues are not an appropriate channel for sensitive reports. Maintainers may remove abusive content or restrict participation.

The [OpenStreetMap Etiquette Guidelines](https://wiki.openstreetmap.org/wiki/Etiquette) and OSM community processes also apply when representing work in OSM forums and mapping discussions.
